# Provas da onda Tabler

Provas por HTTP real contra o Apache, com o Chromium do Playwright, sempre num banco **descartável** (o nome termina em `_teste`) e com os dados da demonstração fictícia.

Nada de endereço ou nome de banco em arquivo versionado: tudo vem do ambiente.

| variável | o quê |
|---|---|
| `VCOSTAEDU_BASE` | o endereço da instalação, com barra no fim |
| `VCOSTAEDU_BANCO_TESTE` | o banco descartável (termina em `_teste`; o reset recusa outro nome) |
| `NODE_PATH` | `tests/tabler/node_modules` (depois de `npm install` nesta pasta) |
