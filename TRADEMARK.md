# A marca VCOSTAEDU

**O código deste projeto é livre. O nome e o logo não fazem parte dele.**

VCOSTA é marca registrada no INPI, e VCOSTAEDU é o nome desta plataforma. O código está sob a licença **AGPL-3.0** — veja o arquivo LICENSE. Este documento fala só da marca, que é outra coisa.

## O que a licença do código garante, e este documento não toca

Você pode **usar, estudar, modificar e redistribuir** este software, inclusive modificado e inclusive comercialmente. Isso é da AGPL-3.0, e **nada aqui reduz essa garantia.**

Nenhum uso do código precisa da nossa autorização. O que este documento trata é apenas do **nome e do logo** — quando você pode usá-los e quando precisa combinar com a VCOSTA.

## O que você pode fazer sem pedir nada

- **Dizer que usa o VCOSTAEDU.** "Nossa secretaria roda VCOSTAEDU", no seu site, no seu material, onde quiser.
- **Escrever sobre o projeto.** Artigo, tutorial, vídeo, curso, crítica, comparação com outro sistema. Inclusive crítica dura.
- **Distribuir uma cópia sem modificação** com o nome VCOSTAEDU. Espelhar o repositório, empacotar para uma distribuição, entregar a uma instituição. É o uso que o projeto espera — quem instala e usa chama pelo nome.
- **Citar o nome** para se referir ao projeto, como em "compatível com VCOSTAEDU" ou "consultoria em VCOSTAEDU", desde que fique claro que você não é a VCOSTA.

## O que precisa de acordo com a VCOSTA

- **Usar o nome ou o logo numa versão MODIFICADA.** Se você mudou o código e vai distribuir, troque o nome e o logo pelos seus — ou combine com a VCOSTA. O seu código modificado continua livre; o que muda é como ele se apresenta.
- **Dar a entender que a VCOSTA endossa, mantém ou dá suporte** ao seu produto, serviço ou versão, quando não é o caso.
- **Registrar domínio, conta, aplicativo ou marca** que se confunda com VCOSTAEDU ou VCOSTA.

## Por que é assim

É o mesmo modelo do Moodle: código livre, marca protegida.

A razão é prática. Se uma versão modificada por terceiros circula com o nosso nome, a instituição que tiver problema procura quem está no rodapé da tela — e a VCOSTA responderia por um comportamento que não escreveu.

O direito de marca é o que separa **"este software é livre"** de **"esta versão é a nossa"**. É ele que nos permite abrir o código inteiro.

## Se você vai distribuir uma versão modificada

Faça o seguinte, e não precisa falar com ninguém:

1. Escolha um nome que não se confunda com VCOSTAEDU nem com VCOSTA.
2. Substitua os arquivos de assets/marca/ pelos seus.
3. Deixe claro no seu material que o seu projeto é derivado do VCOSTAEDU e não é mantido pela VCOSTA.

Dizer *"derivado do VCOSTAEDU"* é permitido e correto — é o oposto de se passar por ele.
