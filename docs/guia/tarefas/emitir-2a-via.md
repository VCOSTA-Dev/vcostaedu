## Para que serve

Entregar de novo um histórico já emitido sem gerar outro documento: mesmo conteúdo, mesmo código.

## Antes de começar

A emissão está **válida** (não cancelada).

## Passo a passo

1. **Educacional → Históricos emitidos** (ou a aba Históricos da ficha), **Ver** na emissão.
2. **Gerar 2ª via**. Sai o mesmo documento, com a marca **"2ª VIA — reimpressão de …"** no topo de cada página; fica registrado quem gerou e quando.
3. Baixe o PDF da via na lista **Documentos**.

## O que pode dar errado

- **"Emissão cancelada não tem 2ª via."**
- **"Os dados gravados desta emissão NÃO conferem com o hash: 2ª via recusada."** — o registro foi alterado; avise o administrador.
- Precisa de um documento com dados novos? Não é 2ª via: emita de novo.
