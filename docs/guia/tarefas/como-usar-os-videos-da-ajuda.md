## Para que serve

Ver a tarefa acontecendo antes de fazer: cada guia tem um vídeo curto que mostra o passo a passo do começo ao fim, na demonstração (com dados inventados).

## Antes de começar

Você precisa estar logado. Cada perfil vê os vídeos dos guias dele.

## Passo a passo

1. Abra um guia (**Ajuda → Central de ajuda**). O vídeo fica no topo, antes do texto. Ele só carrega quando você clica para tocar.
2. A **legenda** já vem ligada: é a narração de cada passo. Para desligar ou mudar a velocidade, use os controles do próprio vídeo.
3. Ao lado do vídeo, os **capítulos**: clique em um para pular direto para aquele trecho. O capítulo que está tocando fica marcado.
4. Abaixo do vídeo, **Ler a transcrição** abre todo o texto narrado.
5. Em **Ajuda → Vídeos** (ou no botão **Vídeos** da Central de ajuda) ficam todos os vídeos do seu perfil, com a duração. Digite no campo de busca uma palavra do título ou do que é dito no vídeo.

## O que pode dar errado

- **O guia não mostra vídeo** — o vídeo daquele guia ainda não foi copiado para o servidor. O texto do guia continua valendo; avise o administrador.
- **"Ainda não há vídeos para os guias do seu perfil."** — a página Vídeos está vazia porque a pasta de vídeos não está no servidor.
- **O vídeo não avança para o meio** — o servidor precisa aceitar o pedido de trecho do vídeo (o Apache aceita); avise o suporte.
